# System Design Checklist

A 10-week system design study checklist. Every topic from the [roadmap.sh System Design roadmap](https://roadmap.sh/system-design), plus the interview topics it misses, with:

- the best free **video or article** for the topic (marked *best*)
- a hands-on **practice task** (many are small Docker labs)
- a checkbox, with progress saved in your browser

## Sections

1. Foundations — networking, DNS, HTTP, estimation, scaling
2. Core building blocks — load balancers, proxies, CDN, caching, availability
3. Databases and storage — SQL vs NoSQL, indexes, replication, sharding, consistent hashing
4. Consistency and distributed systems — CAP, Raft, Saga, Snowflake IDs, Bloom filters, idempotency
5. Communication and async — APIs, WebSockets, queues, Kafka, event-driven, rate limiting
6. Reliability, security and operations — retries, circuit breakers, monitoring, Kubernetes, OAuth, TLS
7. Cloud design patterns (skim)
8. Performance antipatterns (skim)
9. Practice designs — 16 classic interview problems
10. Interview readiness — framework, mock interviews, certification
